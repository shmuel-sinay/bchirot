# מצב הבחירות

אתר סטטי: תוצאות ותחזית מנדטים לכנסת, עם השלמת יישובים שטרם נספרו, חלוקה לגושים וסימולטור אינטראקטיבי.
הרצה מקומית: `python3 -m http.server` ופתיחת http://localhost:8000

## מבנה
- `index.html`, `assets/` - האתר.
- `data/forecast.json` - הנתונים שהאתר טוען (נוצר מהסקריפט).
- `scripts/analyze.py` - סיכום תוצאות קלפיות וחישוב מנדטים.
- `scripts/forecast.py` - התחזית המשוקללת.
- `legacy/` - האתר הקודם (אחוזי הצבעה לפי שכונות, נתוני דמו).

## עדכון הנתונים
```bash
python3 -I scripts/forecast.py <בחירות_קודמות_expb.csv> <בחירות_נוכחיות_expb.csv> data
```
הקלט הוא קבצי תוצאות לפי קלפי של ועדת הבחירות (CSV). בקובץ הקודם חייבת להופיע שורת "מעטפות חיצוניות" (סמל ישוב 9999).

## שיטה
1. סיכום קלפיות שנספרו לפי יישוב והשוואה לבעלי זכות בחירה בבחירות הקודמות, עם תיקון גידול לפי מגזר.
2. רגרסיית ריג' שלומדת מיישובים שנספרו במלואם איך פרופיל הצבעה קודם הפך להצבעה היום, ומשלימה בעזרתה יישובים חסרים. בבדיקה על יישובים מוסתרים השגיאה הממוצעת באחוזי הקולות הארציים כ‑0.17 נקודות אחוז.
3. מעטפות חיצוניות: גודל והרכב מהבחירות הקודמות, בלי רשימות ערביות.
4. אלפי סימולציות לאי ודאות. אחוז חסימה 3.25%, ללא הסכמי עודפים.

זו הערכת מודל ולא תוצאות רשמיות. ביישוב שנספר חלקית לא ידוע אילו שכונות חסרות.
