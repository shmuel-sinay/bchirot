# אחוזי הצבעה לפי שכונות

אתר סטטי: בוחרים עיר ורואים רשימת שכונות ממוינת לפי אחוז הצבעה.
הרצה: `python3 -m http.server` ופתיחת http://localhost:8000

## נתונים
`data/elections.json` מכיל כרגע נתוני דמו בלבד. לנתונים אמיתיים: תוצאות לפי קלפי מאתר ועדת הבחירות
המרכזית (votes.cec.gov.il), וטבלת שיוך קלפיות לשכונות (מהעירייה / הלמ"ס) - יש לכתוב סקריפט המאחד אותם לפורמט הקובץ.

## גוש ימין/שמאל
כרגע מחושב ממיפוי מפלגה→גוש (`parties`) - שקוף וניתן לבדיקה. שלב AI אפשרי בהמשך לסיווג מפלגות חדשות.

## סקרי יציאה / מדגמים
לא ממומש - דורש מקור נתונים חיצוני.
